## Critical Carousel Studio Memory

- Prompt/chat is the only generation entrypoint. Do not recreate header or canvas Generate
  buttons.
- Export belongs in the canvas action bar before Save Draft.
- Create opens a blank unsaved session; prior packages are opened from Drafts/Library.
- Untouched blank sessions are discarded. Dirty new sessions ask save/discard before leaving.
- All live actions need toast or confirmation feedback.
- Captions need hashtag pools: IG/FB 20+, LinkedIn 8-10, TikTok 10+.
- Exported slides must use PAM gradient accents, Montserrat headings, Open Sans body, and
  ratio-aware 1:1 / 4:5 / 9:16 scaling.
