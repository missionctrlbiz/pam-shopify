# Agent Entry Point

The canonical agent protocol lives at `../AGENT.md`.

Key reminders:

- No mock data in live Studio.
- No social publishing in Studio.
- Normalize streamed partials.
- Keep slide actions live and persisted.
- Preserve visual variety.
- Keep generation in the prompt/chat panel only.
- Keep Export in the canvas action bar before Save Draft.
- Create starts a blank unsaved session; do not auto-open previous work.
- Toast or confirm save/export/copy/delete/regenerate/approve/model failures.
- Enforce hashtag floors: IG/FB 20+, LinkedIn 8-10, TikTok 10+.
- Render with PAM gradients, Montserrat/Open Sans, and ratio-aware scaling.
- Deploy Trigger-imported code with `npx trigger.dev@4.4.3 deploy`.
